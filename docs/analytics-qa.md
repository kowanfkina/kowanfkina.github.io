# 网站统计验收范围

- `<head>` 中各出现一次 Clarity、Umami、Google Ads，项目/网站/转化 ID 与用户提供的值完全一致。
- 页面打开只初始化 Google Ads；切换语言、点击功能、切换对比分镜或右击链接均不发送商城转化。
- 导航栏、三组首屏 Banner、页尾商城入口每次实际点击只发送一次 Google Ads 转化；嵌套文本点击也有效。
- 同页跳转使用回调与独立 1 秒超时；Google 脚本被阻止、队列未处理、接口抛错或接口不存在，商城仍可打开。
- Enter、Command/Ctrl、中键和 target=_blank 保留原生操作；修改键与新标签只记录一次点击，当前页不被替换。
- Umami 迟迟未加载时，官网本地交互脚本已经初始化。
- 本地测试使用统计脚本替身；普通导航使用模拟商城，新标签检查验证新标签创建、原生点击未被取消、商城 href 和一次转化；不等待实际 Apple 商品页加载。提供的三个统计账户不会收到测试访问或转化。
- 生成器重复生成后保留追踪代码及版本；Google/Baidu 验证文件保持原格式。

## 2026-10-12 本轮结果

五个商城入口、队列/受阻/抛错/缺失接口回退、Enter/修改键/中键/新窗口、慢 Umami 均通过。头部代码数量和 ID 正确；内部交互不发送商城转化。隐私和条款页面保留初始化，页面访问不等同于商城点击。

右击检查在无窗口 Chromium 中运行，避免 macOS 原生上下文菜单占住测试输入；新标签检查使用同步标签上下文信息，避免尚未提交的外部页面导致浏览器自动化 `opener()` 查询等待。生产统计逻辑未为这些测试环境问题修改。

普通跳转回调约 100–120ms；受阻或队列未处理时约 1.08s 回退。三个正式统计账户均使用本地脚本替身，不以此验证后台收录或实际购买。
