- 局部统计独立模块置于像素对比章节之后；两张原件按中英文展示，包含 RGB/HSV/Y 说明、三个使用要点及放大详情。原件逐字节相同，响应式 WebP 保留 ICC。核对 `PixelSampler.sampleROIResult`，数值为选区均值；未将图像直方图描述为局部直方图。
- 首页、子页和移动导航完整显示 Domino Image Viewer，应用清单名称同步；320px 保留完整名称。极窄屏隐藏导航栏的重复下载按钮，首屏主要商城按钮仍可使用。
- 新隐私与独立使用条款页面保留四语及官网设计，涵盖应用本地数据、授权网络位置/钥匙串、StoreKit、更新检查、官网三类统计、保存/删除和联系。保留原政策/条款 URL 路径形状；线上发布及 App Store Connect 的链接到达尚未验证。
- 首屏初次自动切换至六图、调色台的完整可见时间分别约 1.66s、2.58s；正常阅读循环为 4.5s，滑动 550ms。手动选择/暂停/正文聚焦结束快速序列，减少动态效果时停用自动轮播。网络延迟可能影响图片加载时间。

最终重跑 32 组响应式检查，20 组短屏检查、16 组四语政策与条款往返（32 个子页状态）、无脚本和受限存储均通过。84 次详情、影片、失败重试、实际滚轮分镜及原始 HDR 校验通过。全部三类统计检查通过，见 `analytics-qa.md`。
